# Temple Magazine Studio

Standalone Sanity Studio for project `bry1zd8m` (`production`).

```sh
npm install
npm run dev
```

Studio: http://localhost:3333

Log in with the Sanity account that owns Temple Magazine. If the `production` dataset is missing, create it in [project settings](https://www.sanity.io/manage/project/bry1zd8m).
